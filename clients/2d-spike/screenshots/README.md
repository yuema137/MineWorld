# Stills

All four variants at the same three framings, rendered from one commit so the
comparison is like for like. `06_ref_framing` matches
`presentation/mineworld-default/2D/references/02_cafe_street.png`.

`town` is the accepted default ([`ARC-13`](../../../docs/DECISIONS.md)); the
other three are kept as the demonstration that the presentation layer swaps.

The `town_07`/`08`/`09` stills are the three steps of walking into the café,
and `town_10_stride_a`/`_b` are two frames half a stride apart, which is where
the walk cycle is visible.
