# Change one thing

Each page here starts from the finished Corner Shop of chapter 05, changes one thing, and runs the
world again with the same seed. It shows both outputs side by side, and says why they differ.

Like the chapters, every command and every file on these pages is run by the project's tests on
Linux, macOS and Windows.

| Page | What you change | What changes |
| --- | --- | --- |
| [A forbidden action](a-forbidden-action.md) | nobody may talk in the shop | how much people talk |
| [Weather](weather.md) | the season the world starts in | how often the weather changes |
| [Relationship decay](relationship-decay.md) | liking fades between meetings | how often a friendship changes level |
| One person on a language model | one seat decides with a language model | coming in a later guide update |
| A market day | a market every weekend | coming when happenings land |

The world these pages start from is in [`../examples/corner-shop/`](../examples/corner-shop/world.yaml).
