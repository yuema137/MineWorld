# 只改一处

这里每一页都从第 05 章做完的 Corner Shop 开始，只改一处地方，再用同一个 seed 把世界跑一次。
页面把前后两次的输出摆在一起，再说清楚为什么不一样。

和教程的每一章一样，这些页面里的每条命令、每个文件，项目的测试都会在 Linux、macOS 和 Windows 上真的跑一遍。

这一页翻译自英文原文 [README.md](README.md)。两边不一致时，以英文为准。

| 页面 | 你改什么 | 什么跟着变 |
| --- | --- | --- |
| [不许做的动作](a-forbidden-action.zh-CN.md) | 小店里谁都不许说话 | 大家说话有多少 |
| [天气](weather.zh-CN.md) | 世界从哪个季节开始 | 天气变得有多勤 |
| [关系变淡](relationship-decay.zh-CN.md) | 好感在两次见面之间变淡 | 关系跨级有多勤 |
| 让一个人由语言模型驱动 | 一个 seat 用语言模型拿主意 | 以后的教程更新会补上 |
| 集市日 | 每个周末办一次集市 | 等 happenings 功能上线后补上 |

这些页面开始用的世界，放在 [`../examples/corner-shop/`](../examples/corner-shop/world.yaml)。
回到[教程首页](../README.zh-CN.md)。
