# 搭一个你自己的世界

这份教程教你从一个空文件夹开始，做一个属于你自己的 MineWorld 世界。
你会一步一步搭出一个小世界：**街角小店**（Corner Shop）。它有两个房间、三个人、一家店。

每一步都写成两段：**照着做**，然后**你应该看到**。教程里的每条命令、每个文件，
项目的测试都会在 Linux、macOS 和 Windows 上真的跑一遍。所以你看到的结果应该和教程一样。

本页是英文原文 [README.md](README.md) 的中文镜像。两者不一致时，以英文为准。

## 术语表

教程里第一次出现某个词时，会先用大白话解释，并在括号里写上英文。之后就一直用同一个词。

| 中文 | English | 一句话解释 |
| --- | --- | --- |
| 世界包 | World Pack | 描述一个世界的文件夹：里面有哪些地方、哪些人、用哪些规则 |
| 系统包 | System Pack | 一个模块，负责让一类事情发生，比如走路、说话、买东西 |
| 实体包 | Entity Pack | 一组现成的东西（比如各种商品），任何世界都能拿来用 |
| 包 | pack | 可以安装、可以分享的一份东西；系统包、实体包都是包 |
| 地方 | Place | 人可以待的地方，比如家、小店 |
| 人 | Person | 住在世界里的人 |
| 键 | key | 一个小写的短名字，比如 `ana`；它也是文件名 |
| 座位 | seat | 玩家或程序可以操控的人 |
| 事实 | fact | 世界里发生过的一件事；世界会记下所有事实 |
| 初始事实 | genesis fact | 世界刚开始时就成立的事 |
| 通道 | passage | 两个地方之间的一扇门 |
| 日程 | routine | 一个人每天打算在什么时间待在哪里 |
| 存档 | save | 一个文件夹，保存世界和它发生过的一切 |
| 生平 | biography | 发生在一个人身上、对他的人生有意义的事，按时间排好 |
| 类别 | class | 带同一个标签的一组实体，规则用它来指代一群人 |
| 交互清单 | Interaction List | 这个世界里谁可以对谁做什么、在哪里做 |
| 服务器 | server | 让世界一直运行、让玩家加入的程序 |
| 邀请码 | invite | 玩家加入服务器时要用的一串码 |

每个文件可以写哪些字段，都列在自动生成的[参考手册](../reference/README.md)里（只有英文）。
这些词的准确定义在 [`CORE_CONCEPTS.md`](../CORE_CONCEPTS.md)（英文）。

给智能体（agent）看的：页面格式，以及测试对每一页的要求，写在
[`GUIDE_FORMAT.md`](../GUIDE_FORMAT.md)。
