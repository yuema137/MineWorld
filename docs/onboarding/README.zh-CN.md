# 从一份简述构建世界

> 本文件是 [`README.md`](README.md) 的中文镜像；以英文原文为准。

用几句话或一份简短的 Markdown（任何语言、任何格式）描述你想要的世界，交给你自己的编程 agent（Claude Code、Codex……），只需一句：

> 阅读 `docs/onboarding/ONBOARDING.md`，然后构建这个世界：……

agent 会用可安装的 pack 组合出一个 MineWorld 世界，检查它、运行它，并告诉你怎么玩，以及 MineWorld 目前还做不到什么。之后你们一起继续修改它。

- 简述应当说明什么、哪些留给你的想象：[`BRIEF.md`](BRIEF.md)
- 三个示例简述：[海边度假村](briefs/seaside-resort.md)、[大都市](briefs/metropolis.md)、[山村](briefs/mountain-village.md)
- 想手工构建世界，请看[指南](../guide/README.md)。
