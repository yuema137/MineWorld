# Build a world from a brief

Describe the world you want in a few sentences or a short Markdown file — any language, any shape — and hand it to
your own coding agent (Claude Code, Codex, …) with one line:

> Read `docs/onboarding/ONBOARDING.md`, then build this world: …

The agent composes a MineWorld world from installable packs, checks it, runs it, and tells you how to play it and
what MineWorld cannot do yet. Then you keep changing it together.

- What a brief should cover, and what is left to your imagination: [`BRIEF.md`](BRIEF.md)
- Three example briefs: [seaside resort](briefs/seaside-resort.md), [big city](briefs/metropolis.md),
  [mountain village](briefs/mountain-village.md)
- To build a world by hand instead, follow the [guide](../guide/README.md).
