## ARC-341 — A headless run's stride cadence is a flag, and the seat cap follows from it

**Date** 2026-10-20 · **Status** accepted · **Approved by** the operator, through the coordinator (2026-10-20: "the headless run's seat cap becomes configurable (data/flag) with the current 29 as the default unless a measured reason says otherwise"), on S28-g's material stop D-g-8 · **Relates to** `ARC-27`, `ARC-69`; `step-11-bodies.md` SD-N15, QN-13 · **Design** `.structured-coding/plans/mvp0/pr-s28g-scale-gates.md` (D-g-8)

**Problem.** `mineworld run` consults seat `k` at `genesis + k + n·RUN_STEP` while its person walks, with `RUN_STEP` 30 world seconds. Two seats must never share an instant, so a run refuses a World Pack with 30 or more seats (SD-N15). QN-13 accepted that cap while the largest pack had 11 seats and said a larger pack "moves to a smaller `RUN_STEP` divisor or a sequence tie-break then". S28-g's generated 100-person town has 92 seats, so every scale run is refused.

**Options.**

| Option | Verdict |
| --- | --- |
| (a) Raise the constant | Declined: it changes every existing run's stride cadence, its outputs and its goldens. |
| (b) A tie-break that lets several seats share an instant | Declined: the loop's order would no longer be time order, which the resume arithmetic and `ARC-27`'s restart property rely on. |
| (c) **`--stride SECONDS`, default `RUN_STEP` (30)** | **Chosen.** |

**Choice.** `run` takes `--stride SECONDS`, default 30. The stride must divide the pace (`--pace`, default 900), as `RUN_STEP` did, so the lattice instants stay inside the stride rounds. A run refuses a pack with `stride` or more seats, and the refusal names `RUN_STEP`, the count and `--stride`. A 92-seat pack runs with, for example, `--stride 100` or `--stride 150`. The stride is also what each consult tells the model (`Consult::stride`). Like `--pace`, the stride is not saved: a resume is given the same flags.

**Consequences.** Without the flag, every run is byte-identical to before. With a larger stride, walkers are asked for a stride less often in notional time, which `run` already treats as a choice and not a speed (step-19 §4.6). The default was not changed, because no measurement asked for a change.
