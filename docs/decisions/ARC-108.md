## ARC-108 — Station fixtures show only disclosed state

**Date** 2026-10-15 · **Status** accepted (step plan approved 2026-10-15); implemented by S29-e, S29-f and S29-g · **Approved by** the operator, directly in the primary session, 2026-10-15 (step-29 approval) · **Relates to** `ARC-67`, `ARC-105`, `INV-S27-2`, step-21 §§5.3, 5.7 · **Design** step-29 §§5, 9.4

**Problem.** Before trains exist (S21), a station could easily pretend: an invented timetable, an open ticket window, people waiting for a train that cannot come.

**Choice.**

1. **One pure rule, from disclosed components.** It is written once in `clients/shared/station/station_state.gd` and used by both clients; the agent view renders the same Observation.
   - **The departures board** lists lines only when a `departures` record is disclosed. Otherwise it reads "No service yet".
   - **The ticket window** is open only when its place discloses a `shop` listing a `ticket`-tagged kind.
   - **The kiosk** is open only when the hall discloses a `shop`.
   - **The clock** shows the disclosed world time, or nothing.
2. **No fakes.** No routine label waits for a train before `transport` exists, and no train is drawn before S21's carriage.

**Consequences.** When S21 lands, the board and window come alive with no client change. S21 must disclose `departures` to observers in `station`-tagged places, because a board in the hall cannot perceive the platform's `StopInfo` (a non-preclusion item for RT-c).

**Note, 2026-10-19 (S29-f, `mvp0/pr-s29f`; pr-s29f §5.1, F-S29f-5).** The module is
`MineWorldStationState` (`res://mineworld_station` in each client):

```gdscript
static func of(observation) -> Dictionary
static func evaluate(place_tags: PackedStringArray, departures: Variant, shop: Variant,
		item_tags: Dictionary) -> Dictionary
static func nothing_disclosed() -> Dictionary
# result: { "board": {"state": "none"} | {"state": "lines", "lines": Array},
#           "window": "open" | "shut", "kiosk": "open" | "shut" }
```

The window opens only at a place tagged `ticket-office` whose `shop` lists an item whose perceived tags
include `ticket`. A shop discloses item ids, not kinds' tags, and item kinds are not perceived, so today the
window is shut everywhere: fail-closed, the true state before trains. S21 RT-c must let the observer of a
ticket office perceive the tags of the kinds its shop lists (R-RTc-f-1). A fixture of a place the observer
does not stand in is drawn from `nothing_disclosed()`. The clock is not in this module yet; S29-e adds it
here, with a case in `clients/shared/checks/station_state_check.gd`, if its design needs it (R-S29e-f-1).

**Note (2026-10-20, S29-g) — the agent view.**
- The agent view carries `PlaceLine.roles`: the role tags of `CORE_CONCEPTS.md` §6.6, in that order, ahead of
  `labels`. It says nothing else about the station.
- It shows no service state. The agent reads the same disclosed facts the clients' rule reads: `shop` on the
  ticket office and in the hall, and `departures` once S21 defines it. A record the adapter does not know is
  carried verbatim by `inspect` (F-S29g-4, F-S29g-5).
- As Q-S29g-2 ruled: a role tag grants no behaviour; a client may order lines or choose a drawing by role tag
  (F-S29g-1).

**Note (2026-10-20, S29-e) — the shared module, remembered state, the clock, `departures`.**
- The rule is written once, in `clients/shared/station/`: S29-f's `MineWorldStationState` (board, window,
  kiosk; adopted unchanged by S29-e) and S29-e's `MineWorldStationClock`. Both are pure: they read only what one
  observation discloses on the observer's place, and `at`. The window and kiosk rule reads the place's
  `ticket-office` role tag, as S29-f wrote it: a role tag decides which fixture reads which field, never a state.
- **Remembered state (Q-S29e-2, ruled 2026-10-19).** A fixture in another place than the observer's -- the ticket
  window seen from the hall -- shows the state of the last observation made in its place, and the defaults (shut,
  "No service yet", no hands) for a place never observed. A remembered state is a disclosed state; an invented one
  is not. The 3D client keeps it per place in `StationFixtures`; S29-f's 2D fixtures keep it the same way.
- **The clock (F-S29e-5).** The disclosure that a world keeps a calendar is a `calendar-day` record on the
  observer's place. Where it is disclosed the clock shows the observation's time of day; where not, no hands.
  The host's wall clock is never read.
- **`departures` (Q-S29e-3, ruled 2026-10-19).** Provisional shape `{lines: [{line, next: [world seconds]}]}`.
  S21's RT-c adopts it, or changes the adapter and the table rows in the same PR (R-S21-e-1).
