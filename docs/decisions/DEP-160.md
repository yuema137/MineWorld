## DEP-160 — Cast base colours: Godot's built-in Basis Universal (UASTC + RDO), 2048² kept

**Date** 2026-10-20 · **Status** accepted · **Approved by** operator ruling 2026-10-19 ("NPC models go in now, package size gets compressed later — now is later"), relayed by the primary session; within Q-S26-5 O-1 · **Relates to** `DEP-41`, `ARC-80`, [`REUSE_POLICY.md`](../REUSE_POLICY.md) · **Design** `.structured-coding/plans/mvp0/step-26-cast.md` §10.3 (Q-S26-5); `.structured-coding/plans/mvp0/step-23-release.md` §18 (MS-Ra-2)

**Problem.** The S23 packager measured the macOS universal bundle at 581.3 MB (hard limit 400) and `3d.pck` at
422.4 MB compressed (hard limit 250). The 22 cast base colours (21 cast members and `meshy_d`, each a 2048² RGB
`<id>_base_color.png`) were imported Lossless: about 6.0 MB each inside the pack and almost incompressible, 132.2 MB
in all. Godot imports a new texture Lossless by default, so every character the pipeline adds repeats it.

**Options compared** (one cast map, Godot 4.7.2's own importer, bytes after zlib level 6 as the packager counts them;
texel PSNR is the decoded map against the source):

| `.import` setting | Bytes in the pack | Texel PSNR | Note |
| --- | --- | --- | --- |
| `compress/mode=0` Lossless (before) | 6.20 MB | ∞ | |
| `mode=2`, `high_quality=true` (BC7) | 4.88 MB | 46.5 dB | needs a second ETC2/ASTC copy for the macOS universal export's import |
| `mode=2`, `high_quality=false` (DXT1) | 2.12 MB | 34.2 dB | visible blocking on skin (`patch_imports.py`'s own earlier finding) |
| `mode=4` Basis UASTC, level 0, RDO 0 | 4.67 MB | 45.8 dB | |
| `mode=4` Basis UASTC, level 2, RDO 2 | 4.26 MB | 42.5 dB | |
| **`mode=4` Basis UASTC, level 0, RDO 4** | **3.58 MB** | 38.1 dB | chosen |

**Choice.** `compress/mode=4` (Basis Universal; Godot 4.7.2 encodes UASTC, supercompressed), `uastc_level=0`,
`rdo_quality_loss=4.0`, mipmaps on, `detect_3d/compress_to=0`. One file per texture, transcoded at load to BC7 on
desktop GPUs and ASTC/ETC2 elsewhere, so the macOS universal export needs no second copy. This is Q-S26-5's ruled
option O-1, done with the engine's own encoder: no new dependency.

**Visual check** (3D client lighting, `CameraRig.FOV` 70°, 1920×1080; renders and numbers in
`mineworld-demos/video/verify-1019/fixes/tex-*`). "face" is the closest framing the client allows: a first-person eye
0.50 m from the face (two 0.25 m body radii touching); "talk" is chest-up at 1.20 m. PSNR/SSIM against the Lossless
render, on the character crop:

| --- | --- | --- |
| alba-ferreira | 46.8 dB / 0.9931 | 51.8 dB / 0.9975 |
| dario-russo | 44.2 dB / 0.9876 | 50.0 dB / 0.9971 |

**Superseded in part by `DEP-162`** (operator ruling 2026-10-20): the release now ships these maps at 1024², RDO 1.0.
The paragraph below is kept as the record of why 2048² was kept until then.

**Why 2048² stays.** The same face framing with the map capped at 1024² (`process/size_limit=1024`, BC7) gives 41.2–43.5
dB and SSIM 0.979–0.987, and the side-by-side is visibly softer. So the 2048² texel density is not above what the
camera shows at its closest, and no downscale is applied (Q-S26-5 keeps 2048² as the standard).

**Mechanism.** `clients/3d-spike/tools/patch_imports.py` owns the setting as the `cast_albedo` role. It applies to
every `assets/characters/**/*_base_color.png.import` by the pipeline's stored-once file name, so a re-export of a body
(the `.gltf`/`.bin`) keeps it and a new character gets it by running the tool. `patch_imports.py --check` exits 1 for a
base colour that is off the role.

**Measured result** (S23 packager, `assemble --target macos-universal --clients 2d,3d` on the C6 tree that measured
422.4 MB, with only these 22 `.import` files changed): `3d.pck` **422.4 → 364.8 MB** compressed (−57.6 MB; the 22 maps
132.2 → 74.6 MB); the archive **581.3 → 523.7 MB**. Both stay over their hard limits (250 and 400).

**Not enough alone.** The rest of `3d.pck` is 290 MB compressed (230 other textures 211 MB, the cast scenes 72 MB), so no
setting on the cast base colours can bring it under 250 MB. The props' textures and the cast meshes are the next levers.
