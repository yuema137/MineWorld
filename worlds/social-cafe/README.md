# `social-cafe`

The world the MVP-0 vertical slice is set in: one café, three people, and the two systems that make
being there mean anything.

```text
world.yaml        what this world is, what it enables, who is in it, and which seat a client takes
places/cafe.yaml  the one room
people/*.yaml     Alice behind the counter, Bob at a table, and the visitor at the door
```

Run it:

```sh
mineworld server worlds/social-cafe
```

It is content, not code: no rule of the simulation is written here, and none can be. What a pack may
say is specified in [`docs/MODULE_SPEC.md`](../../docs/MODULE_SPEC.md) §4.
