# Provenance — the station's reference photographs (HABS CA-1965)

Reference photographs of the Santa Fe Depot, San Diego (1915; NRHP 72000248), for the station kit
`stations/depot.yaml` (`ARC-106`, `ARC-192`, S29-d). They are the evidence for the kit's measured values
(`MEASUREMENTS.md`). They are references, not runtime assets: nothing under `presentation/` is exported
into `3d.pck`.

## 1. Origin and terms

| Field | Value |
| --- | --- |
| Source | Historic American Buildings Survey, *Santa Fe Railroad Station, 1050 Kettner Boulevard, San Diego, San Diego County, CA*, survey number HABS CA-1965, Library of Congress call number **HABS CAL,37-SANDI,22-** |
| Licence | public domain: a work of the United States federal government (HABS, National Park Service); no known restrictions. `DEP-8`; step-29 Q-S29-8 allows HABS photographs to be committed |
| Fetched from | Wikimedia Commons' copies of the Library of Congress files, because the Library of Congress answers automated requests with HTTP 403 (S29-d A-22, R-d-4). Each Commons file is identified by its HABS call number and photograph number in its title, the same number printed on the negative's border |
| Form | Commons' 1 920-pixel JPEG derivative of each TIFF, as served on 2026-10-20 (the files are not re-encoded here) |
| Fetched by | a standard-library Python script in the lane's scratch directory (`commons_fetch.py`, not committed), 2026-10-20 |
| Not committed | the HABS data pages (no copy found on Commons; the Library of Congress refuses automated fetches); any CC BY-SA photograph (Q-S29-8) |
