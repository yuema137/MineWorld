# Art direction — default 2D

Canonical direction: [`../../../docs/ART_DIRECTION.md`](../../../docs/ART_DIRECTION.md), §20 for
2D specifically.

This pack is a clean illustrated isometric style. It does not imitate the 3D references, and it
is not required to: what it preserves is the mood — calm, ordinary, warm, walkable, human-scale,
environmentally readable — and, strictly, the semantics. The 2D and 3D packs must represent
identical semantic interactions.

References live in [`references/`](references/) and are the source of truth for this style;
[`manifest.yaml`](manifest.yaml) is their compact summary.
