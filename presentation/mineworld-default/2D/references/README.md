# Reference images — default 2D style

These define the 2D look. Prose and the manifest summarise them; when they disagree, the images
win ([`../../../../docs/ART_DIRECTION.md`](../../../../docs/ART_DIRECTION.md) §16).

All four are AI-generated (ChatGPT); origin and terms: [`PROVENANCE.md`](PROVENANCE.md).

| File | Covers |
| --- | --- |
| `01_town_square.png` | square with fountain, café with outdoor seating, bakery, bookshop, lake edge and jetty, a pedestrian with a dog |
| `02_cafe_street.png` | café frontage with a seated customer, bookshop and flower shop, bicycle, crosswalk, wayfinding signs |
| `03_harbour_cafe.png` | harbour café, jetty and moored boat, a character seated on a bench with coffee, two seated at an outdoor table, a cat |
| `04_lakeside_park.png` | park and residences: pond with ducks, footbridge, someone picnicking on the grass, an older person seated on a bench, apartment block |

What they establish: clean illustrated isometric projection, moderate stylization, stylized
character proportions, low material detail, soft daylight with warm lamp accents, medium density,
and high readability — walkable ground, entrances and interactive objects are legible at a glance.

Two things they already show that matter beyond art: **seated characters**, which is the `Sit`
affordance in 2D form, and **legible signage**, which is how a 2D client conveys place identity
without a label system.

Still uncovered: an interior at room scale, and a night or overcast condition. Follow-up work,
**not an MVP-0 blocker**.

These are style references, not game content (§14).
