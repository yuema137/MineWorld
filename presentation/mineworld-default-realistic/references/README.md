# Reference images — the source of truth for this style

These images define the default MineWorld look. Prose and the manifest summarise them; when they
disagree, the images win ([`../../../docs/ART_DIRECTION.md`](../../../docs/ART_DIRECTION.md) §16).

When reviewing a visual change, the question to ask is simply: *does this still look like it
belongs in the same world as these?*

## What is missing

`ART_DIRECTION.md` refers to **four** approved references; one is present. Three are still
needed, and the gap is real rather than cosmetic: a single image under-determines the style,
particularly for interiors, characters at close range, and night or overcast conditions.

Useful additions would cover an interior (a café or shop from inside), people at conversational
distance, and a non-golden-hour lighting condition.

These are style references, not game content: they fix realism level, lighting, material
complexity, density, architectural credibility, character realism, colour and human scale — not
the town MineWorld must build (`ART_DIRECTION.md` §14).
