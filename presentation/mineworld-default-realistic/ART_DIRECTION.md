# Art direction for this pack

The canonical art direction for the default MineWorld style is
[`../../docs/ART_DIRECTION.md`](../../docs/ART_DIRECTION.md). It is kept at project level because
it also defines the Presentation Style Pack format itself, which every style uses.

This pack is the default style described there. Its references live in [`references/`](references/)
and its machine-readable summary is [`manifest.yaml`](manifest.yaml).
