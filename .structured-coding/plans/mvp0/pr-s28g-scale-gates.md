## 1. Goal

S28-a … S28-f prove memory correct on 12 people over 30 days in per-PR CI. Nothing proves it stays bounded and
correct at the scale the step promises: 300 days, and 100 people. After this PR, every night, on Linux, macOS and
Windows:

1. **12 people × 300 days** (`social-cafe`, seed 7) and **100 people × 300 days** (a generated town) run through
   the shipped memory code: real `mineworld run`, real `mineworld perceived` exports, `absorb` with the default
   retention and the stack `person`, `place`, `item`.
2. **The cost formulas are checked** (§5.5): every seat view within its bound after every ingest call and every
   pass; physical ≤ logical; the file and the process memory within their formulas; ten sampled seats rebuilt alone
   give byte-identical seat views; at 300 days the café's physical bytes are at most 70 % of logical; continuity
   C-7 and C-8 hold at 300 days.
3. **The 100-person town is generated** by a committed, generic tool, `tools/worldgen/tile.py`, that tiles any
   World Pack into a larger one. It finds every reference to a place, person or item from the repository's own
   generated JSON Schemas, so it names no world, section or key.
4. **Each night writes its measurements** (wall time per phase, facts per second, bytes, peak RSS) to
   `artifacts/nightly/timings-memory-scale.json`, so a slow-down or a growth is visible as a trend before it is a
   failure.

Nothing changes in memory's behaviour. The one source change is `MemoryHome.dump_lines()` (§5.4), a streaming
form of `dump()` that gives the same bytes without building a 1 GB string. Nothing changes under `kernel/`,
`contracts/`, `server/`, `persistence/`, `systems/`, `worlds/` or `sdk/`.

### 5.2 The tiler (`tools/worldgen/tile.py`)

**What it does, in one sentence.** It copies a World Pack K times as K independent "blocks" of the same town,
gives every place, person and item of block *b* the key `<key>-<bb>`, rewrites every reference inside a block to
that block's copy, and keeps only as many people as asked.

**Command.**

```text
uv run --locked python tools/worldgen/tile.py --source worlds/social-cafe --people 100 --id town-100 \
    --out <dir> [--schemas docs/reference/schema]
```

- `blocks = ceil(people / len(source population))`. Person *p* (0-based, in the source population's order,
  repeated) goes to block `p // n + 1`. For the café, 100 people make 8 full blocks of 12 and a 9th block with
  `alice`, `bob`, `carol`, `dev`. Every block gets every place and every item.
- Keys: `<key>-<bb>`, `bb` two digits from `01`. A source key longer than 61 characters is refused
  (`EntityKey` allows 64).
- `world.id` becomes `--id`; `world.name` becomes `"<source name>, tiled <blocks> times"` (ASCII only).
- **References, found from the schemas.** The tiler loads `world.schema.json`, `place.schema.json`,
  `person.schema.json`, `item.schema.json` and, for each top-level key `<s>` of a place, person or item file that
  the base schema does not define, `section-<s>.schema.json`. It walks each YAML value beside its schema node
  (`properties`, `items`, `additionalProperties`, `$ref` into `$defs`, `anyOf`/`oneOf`: the first branch whose
  type matches the value). A value at an `EntityKey` node is a reference.
  - Inside a place, person or item file of block *b*: the reference `k` becomes `k-bb`.
  - In `world.yaml`, a list of references (`places`, `items`, `population`, `seats`) becomes, block by block, the
    copies that exist (so the 9th block's seats are only its four people's).
- **Names.** A person's `name` (the `naming` section) becomes `"<name> <b>"` for block *b* ≥ 2, so every name
  stays unique; block 1 keeps the source names.
- **Copied as they are:** `mineworld`, `requires`, `systems`, `hosting`, `configure` (the list) and every
  `configure/<key>.yaml` whose schema has no `EntityKey` node holding a value; every non-reference field.
- **Refused by name** (`TileRefused(what, why)`, exit 2, nothing written): an `organizations` section or
  directory; a configure file that holds a reference; a section key with no `section-<key>.schema.json`; a
  reference to a key the source does not define; an output directory that exists.
- **Determinism.** Files are written in key order; YAML with `sort_keys=False` (the source's own order),
  `allow_unicode=True`, `width=100`, LF line ends on every OS; each file starts with `# Generated by
  tools/worldgen/tile.py from <source> (people <N>, blocks <K>). Do not edit; regenerate.` The same arguments give
  byte-identical output on every OS.
- **Python surface** (pyright strict): `tile(source: Path, people: int, world_id: str, schemas: Path) ->
  dict[PurePosixPath, str]` (pure: reads, returns the files); `write(files, out)`; `main(argv) -> int`.

**Why independent blocks [QS28g-1].** Linking blocks needs new passages, and a passage needs two points on two
floors that avoid every solid: geometry the tiler would have to invent per world. Independent blocks need none,
and they keep each person's perception rate the café's, so the 100-person run measures what grows with the number
of seats (the home, its indexes, the process), which is the step's question (§17's contention risk).

### 5.3 The scale harness (`tests/scale_harness.py`)

```python
@dataclass(frozen=True)
class ScaleSpec:
    world: Path; days: int; seed: int; frame: int            # frame 4096
    homes: Literal["one", "per-block"]; workers: int
    sample: int                                              # seats rebuilt alone (10)
    continuity: bool                                         # C-7 / C-8 recall points (the café only)

@dataclass(frozen=True)
class SeatResult:
    seat: str; facts: int; passes: int; largest_size: int; largest_after_pass: int
    size: int; dump_sha256: str | None                      # sha256 only for sampled seats
    l2_empty_days: tuple[int, ...]; most_met_in_l3: bool | None; unexplained: int | None

@dataclass(frozen=True)
class HomeResult:
    path: str; seats: tuple[SeatResult, ...]
    physical: int; logical: int; file_bytes: int; peak_rss: int
    anchor_rows_max: int; wall: dict[str, float]

def run_world(spec, scratch) -> tuple[Path, WorldInstanceId]          # mineworld run …, inspect
def people(world) -> list[tuple[EntityKey, str]]                      # (key, name) from people/*.yaml
def frames(world, save, person, size) -> Iterator[list[PerceivedEvent]]   # a Popen pipe, never a file
def absorb_group(spec, save, instance, group, home_path) -> HomeResult    # runs in a worker
def rebuild_alone(spec, save, instance, seat, path) -> str            # sha256 of the seat view, frames 256
def peak_rss_bytes() -> int                                           # this process's peak, per OS
def check(spec, results, bounds, memory) -> list[str]                 # every S-n violation, as text
def timings(spec, results) -> dict[str, JsonValue]                    # written to artifacts/nightly/
```

- **The run.** `mineworld run <world> --headless --seed <seed> --days <days> --save <scratch>/save`; the instance
  from `mineworld inspect` (as `cafe12`).
- **The stack.** `mineworld decisions <world> --decisions tests/fixtures/scale.decisions.yaml --json`, read with
  the controller's reader; its `memory.default` choice is resolved with S28-c's `resolve(…, seat=…)` and
  `resolve_stack(…)` for every person (non-seats included: memory is the controller's, and every person
  perceives). C0 fixes the exact reading path.
- **Groups.** `homes = "one"`: one group of every person, one home. `homes = "per-block"`: one group per block
  (people whose key ends `-<bb>`; the café is one block). Each group runs in its own worker process
  (`ProcessPoolExecutor(max_workers=workers, mp_context=get_context("spawn"))`). A group's home is
  `MemoryHome.open(<scratch>/store/<instance>/<group>.sqlite, instance, page_cache_kib=MemoryConfig().page_cache_kib)`.
- **Inside a group.** Persons in key order, one after the other (seat-major; I-S28-5 makes the final home the
  same for any interleaving, and AS28-3's per-PR harness owns interleavings). For each person: `home.seat(identity)`
  (the entity from the `named` fact, as `cafe12`); for each frame of `frames(...)`: `report = run(absorb(view,
  frame, frame[-1].id, retention))`; then record `view.size()` and each `PassReport.bytes_after`. At the end:
  `home.reclaim()`; `physical = Σ len(line) over home.dump_lines()`; `logical = Σ view.size()`; `file_bytes` = the
  home file plus any `-wal` / `-journal` beside it; `peak_rss_bytes()`; the `anchor_known` row count per seat
  (S28-d's read, C0).
- **Continuity points** (`continuity = True`): for sampled seats, at the first fact of each simulated day from day
  8, the frame is split there, and `memory_view(view, stack, RecallQuery(at=<that fact's at>, …))` is taken
  (S28-c's signature, C0); a day whose L2 section is empty is recorded. At the end: the counterpart with the most
  perceived facts in the seat's stream (an oracle counted by the harness from the stream it fed, never from
  memory) must be named in L3; 1 000 ids drawn (SplitMix64, seed 7) from the seat's stream are explained by S28-e's
  `inspect` API, and any id it calls "never perceived" counts as unexplained.
- **Sampled rebuild.** After the groups end, `sample` seats drawn with SplitMix64 (seed 7) over the sorted keys are
  each rebuilt alone in a fresh one-seat home from a null cursor, frames of 256, in reverse key order;
  `rebuild_alone` returns the sha256 of `SeatView.dump()`.
- **Never** a file of perceived facts on disk (≈ 200 MB per person-year); never `verify` (its per-pass full dumps
  would dominate the run; the per-PR suites own `verify`).

**The smoke test** (`tests/test_scale_harness.py`, `real_binary`, per PR): tile the café to 24 people into
`tmp_path`, run 2 days, run the harness with `homes = "per-block"`, `workers = 2`, `sample = 2`; `check(...)` returns
`[]`; then each S-n check is shown to fire by feeding `check` a copy of the results with one planted violation
(a size over the bound, physical > logical, a file over its formula, an RSS over its formula, a sampled sha256
that differs, an L2-empty day, an unexplained id) and asserting the matching message.

### 5.4 The streaming dump (`memory/home/home.py`)

`MemoryHome.dump_lines() -> Iterator[str]` yields the canonical lines in exactly `dump()`'s order (fact records,
then each seat's private tables in seat order, then shared scope rows), each without its newline.
`dump()` becomes `("\n".join(self.dump_lines()) + "\n").encode("utf-8")` and must give the same bytes on every
existing fixture (the golden and transparency suites, unchanged, prove it). Nothing else changes.
